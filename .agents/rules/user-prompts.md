# User Prompt History Standards

## 1. Maintenance of `prompts.md`
- Always maintain a file in the workspace root named `prompts.md`.
- This file is dedicated strictly to capturing user-provided prompts.

## 2. Strict Filtering (No AI Conversations)
- Save **ONLY user-provided prompts**.
- Never include AI-generated conversations, responses, summaries, thinking, or commentary in `prompts.md`.

## 3. Format & Structure
- Format entries chronologically under clear markdown headers:
  ```markdown
  ## Prompt <N>
  <Exact user prompt text>
  ```
- Preserve exact user formatting and wording without alterations.
